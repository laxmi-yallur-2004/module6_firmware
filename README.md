# Module 6: ADC DMA + UART RX DMA (STM32 Black Pill F401CC)

## Connection

| Signal | Pin | Connect to |
|---|---|---|
| ADC input | PA0 | analog voltage (0 to 3.3 V) |
| UART TX | PA9 | RX of the USB-serial adapter |
| UART RX | PA10 | TX of the USB-serial adapter |
| GND | GND | GND of the adapter and the voltage source |

Serial terminal: 115200 baud, 8N1.

## Task 1: ADC sampling using DMA

- The ADC reads PA0 continuously (12-bit).
- DMA writes the samples into an 8-slot circular buffer without using the CPU.
- When the first 4 (or last 4) slots are full, an interrupt saves that block.
- Every 0.5 s the main loop takes a stable copy of one block and prints the 4 samples, their average and the millivolts.
- Blocks that are overwritten before being printed are counted as dropped.

## Task 2: UART RX using DMA

- Received bytes go into a 256-byte circular DMA buffer.
- DMA interrupts (every 128 bytes) move them into a 1024-byte ring buffer (1023 usable slots), so long prints cannot cause lost bytes.
- The main loop reads the ring buffer and echoes the text back.
- Completed DMA laps are counted, so bytes overwritten by the DMA before being read are counted as `dma lost`.
- If the ring buffer is full, the byte is dropped and counted as `ring overflow`.
- A `[FAULTS]` line is printed only when a fault happens. No line means no faults:

```
[FAULTS] ring overflow: N | dma lost: N | uart err: N | adc err: N | tx err: N
```

**How to read the output**

- FIRST / SECOND HALF: samples 1-4 and 5-8.
- block #N: how many times that half was filled since power-on.
- Sample: raw 12-bit value and voltage in mV (`raw x 3300 / 4095`).
- ADC BLOCKS DROPPED: large on purpose, the ADC is much faster than the 0.5 s print rate.
- UART DMA HIGH-WATER: most bytes ever waiting in the UART DMA buffer (max 256). 128 is the half-buffer interrupt point.
- The ADC output appears in the middle of the echoed text because both use the same serial port.
